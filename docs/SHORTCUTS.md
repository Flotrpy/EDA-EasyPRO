# Default keyboard shortcuts

All of these can be rebound in **Settings → Keyboard Shortcuts**. Keys marked
*Schematic* or *PCB* only apply in that editor.

## Everywhere

| Key | Command |
|---|---|
| Ctrl+K, Ctrl+Shift+P | Command palette (commands, parts, designators) |
| Ctrl+S / Ctrl+Shift+S | Save / Save As |
| Ctrl+O | Open project |
| Ctrl+Alt+N | New project |
| Ctrl+Z / Ctrl+Y, Ctrl+Shift+Z | Undo / Redo |
| Ctrl+B / Ctrl+J / Ctrl+Alt+P | Toggle left, bottom, properties panel |
| Shift+F | Component library |
| Alt+1 / Alt+2 / Alt+3 | Schematic / PCB / 3D |
| Ctrl+, | Preferences |
| ? | Shortcut reference |
| Esc | Cancel the current action, then the tool, then the selection |

## Editing (schematic, PCB, symbol and footprint editors)

| Key | Command |
|---|---|
| S | Select tool |
| R, Space | Rotate 90° (also while placing) |
| Delete, Backspace | Delete |
| Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D | Copy / Cut / Paste / Duplicate |
| Ctrl+A | Select all |
| Arrows (Shift+Arrows) | Nudge by one (ten) grid steps |
| Home, Ctrl+0 | Fit all |
| Z | Zoom to selection |
| = / - | Zoom in / out |

## Schematic

| Key | Command |
|---|---|
| W | Wire (/ flips the bend, Backspace removes a corner) |
| N | Net label |
| P / G | Power / ground flag |
| Shift+X | No-connect flag |
| T | Text |
| X | Mirror |
| Ctrl+U | Update PCB |
| Ctrl+Alt+E | Electrical rule check |

## PCB

| Key | Command |
|---|---|
| W | Route track (V via + layer change, / bend, Esc finish) |
| V | Via |
| E | Copper area |
| L | Silkscreen line |
| Shift+T | Silkscreen text |
| M | Measure |
| T / B | Top / bottom layer active |
| Ctrl+Alt+L | Next copper layer |
| F | Flip part to other side |
| Q | Toggle mm / mil |
| Shift+B | Rebuild copper areas |
| Alt+N | Select whole net |
| Ctrl+Alt+D | Design rule check |
| Ctrl+Alt+G | Fabrication package |
| Alt (hold) | Move or draw off-grid |

## Symbol and footprint editors

| Key | Command |
|---|---|
| P | Pin (symbol) / SMD pad (footprint) |
| H | Through-hole pad |
| L | Line |
